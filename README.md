# CleanNest — cleannest.in

Static site for **CleanNest — Deep Cleaning Services, Jalandhar** (Punjab, India).

- **Production domain:** https://www.cleannest.in (HTTP 200 verified)
- **Preview URL:** https://zyekr0007-alt.github.io/cleannest/
- **Repo:** github.com/zyekr0007-alt/cleannest — GitHub Pages auto-deploys from `main` (no build step)

## Stack

- Plain static HTML/CSS/JS — no framework, no build step, no dependencies
- Fonts: **Ultima** (brand lockup, local `assets/fonts/Ultima.ttf` + `assets/fonts/UltimaBold.ttf`) + **Nunito** (body/headings) with Interspersed `Inter` for some UI text
- Design system: glassmorphism on light off-white bg, **navy `#0B4364`** + **cyan `#0CD7E5`** brand palette, rounded 16px cards, soft navy-tinted shadows, gradient text on hero words
- All JS is **inline `<script>`** per page (no separate `.js` file)
- Site spec: `CONTENT_ARCHITECTURE.md` is the source of truth for info architecture, copy, and brand voice

## Editing

- Edit any page's HTML directly; **`style.css`** (repo root) holds all styles (the old `assets/css/` + `assets/js/main.js` no longer exist — JS is inline).
- Service pages are generated from `build_service_pages.py`; if you change shared service-page structure, regenerate there.
- Verify locally: `python3 -m http.server 8123` in this dir, open http://localhost:8123
- Commit to `main` — GitHub Pages deploys automatically.
